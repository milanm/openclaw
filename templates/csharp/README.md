# C#/.NET Project Template

Production-ready C#/.NET project template with OpenClaw best practices.

## Quick Start

```bash
dotnet new console -n MyProject
cd MyProject

# Copy template files here
# Install dependencies
dotnet restore
```

## What's Included

- **AGENTS.md** - AI coding assistant guidelines for C#
- **.editorconfig** - Code style configuration
- **.gitignore** - Standard .NET ignores
- **Directory.Build.props** - Shared MSBuild properties
- **Example source and tests**

## Features

- ✅ Latest C# version
- ✅ Nullable reference types enabled
- ✅ Code analysis enabled
- ✅ Test project with xUnit/NUnit
- ✅ GitHub Actions CI/CD
- ✅ AI assistant ready

## Commands

```bash
dotnet build              # Build solution
dotnet test               # Run tests
dotnet run                # Run application
dotnet format             # Format code
dotnet publish -c Release # Publish release
```
