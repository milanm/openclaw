# Ruby Project Template

Production-ready Ruby project template with OpenClaw best practices.

## Quick Start

```bash
bundle init
# Add gems to Gemfile
bundle install
```

## What's Included

- **AGENTS.md** - AI coding assistant guidelines for Ruby
- **Gemfile** - Dependency management
- **.rubocop.yml** - Ruby style guide
- **.gitignore** - Standard Ruby ignores
- **Example source and tests (RSpec/Minitest)**

## Features

- ✅ Latest Ruby version
- ✅ RuboCop for linting
- ✅ RSpec/Minitest for testing
- ✅ GitHub Actions CI/CD
- ✅ AI assistant ready

## Commands

```bash
bundle exec rake        # Run default task
bundle exec rspec       # Run tests
bundle exec rubocop     # Lint code
bundle exec rubocop -a  # Auto-fix issues
```
